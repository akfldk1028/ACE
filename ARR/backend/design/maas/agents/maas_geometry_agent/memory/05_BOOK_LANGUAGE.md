# BOOK language

The BOOK is a compositional graph with 13,662 executable paths across six
fraction scopes, three orientations, thirty base operative semantics, bounded
variations, combination edges, aggregation methods, and case-study relations.

The LLM selects and composes from the graph. Twenty is the final selected set,
not a twenty-row recipe table. No operator is mandatory across the portfolio.
Taper, step, shear, court, bridge, bend, pinch, inflate, overlap, interlock,
split, lodge, carve and all other valid relations compete as graph nodes.

Candidate identity binds base form, fraction, orientation, Matrix4, exact path,
topology, operations, and parameters. Numeric-only variants do not establish
architectural diversity.
