## 📐 슬라이드 3 — 교배 (Crossover, BLX-α)

### 한 줄 요약
> *부모 두 매스에서 자식 매스를 만드는 방법. 단순 평균이 아니라 부모 둘 사이 + 양 끝 바깥 1/3까지 무작위로 뽑는다.*

### 구체적 예시 (숫자로 보면 이해 쉬움)
부모 A의 첫 번째 유전자 값 = **5**
부모 B의 첫 번째 유전자 값 = **8**

→ 둘 사이 거리 `d = |5 - 8| = 3`
→ 자식의 첫 번째 유전자 = `Uniform(5 - 3/3, 8 + 3/3)` = `Uniform(4, 9)` 사이 무작위

즉 자식은 4 ~ 9 사이 어딘가의 값. *부모 둘 사이(5~8)뿐 아니라 양 끝 바깥(4와 9)까지 1만큼 더 넓게* 뽑힙니다.

### 왜 단순 평균이 아닌가?
- 단순 평균이면 자식 = (5 + 8) / 2 = **6.5 고정**
- 매번 평균만 내면 *새로운 시도가 없어* 진화가 보수적
- 1/3 확장하면 부모 둘이 못 가본 영역(4 미만, 9 초과)까지 자식이 시도 가능
- 부모 둘이 *멀리 떨어진* 특성을 가지면(d가 크면) 자식의 탐색 범위도 *비례해서* 넓어짐

### 29개 유전자에 모두 적용
매스 한 개 = 29개 숫자. 자식 1명 만들 때 *29번* 이 BLX-α를 따로따로 수행. 어떤 유전자는 부모 A에 가깝게, 어떤 유전자는 부모 B에 가깝게, 어떤 유전자는 둘 다 못 가본 바깥쪽으로.

### 코드 한 줄씩 풀이
```python
def crossover(self, parent_a, parent_b):
    d = abs(parent_a - parent_b)            # ① 두 부모 거리
    return random.uniform(
        min(parent_a, parent_b) - d / 3,    # ② 작은 쪽에서 1/3만큼 더 작게
        max(parent_a, parent_b) + d / 3     # ③ 큰 쪽에서 1/3만큼 더 크게
    )                                        # ④ 그 범위 안에서 무작위
```

### 발표할 때 한 줄
> "단순 평균이 아니라 부모 둘 사이뿐 아니라 *양 끝 1/3 바깥*까지 무작위로 뽑아서, 부모가 못 가본 영역도 자식이 시도할 수 있게 하는 BLX-α 방식입니다."

## 🎲 슬라이드 4 — 돌연변이 (Adaptive Gaussian Mutation)

### 한 줄 요약
> *자식 유전자 일부를 무작위로 흔드는데, 처음엔 크게 나중엔 작게 자동 조정.*

### 두 가지 핵심을 분리해서 보기

#### (가) **얼마나 자주 흔드냐** (변이율 mutation_rate)
- 자식의 *각 유전자마다 동전 던지기*. 앞면이 나오면 흔들고, 뒷면이면 그대로
- 동전 앞면 확률 = `mutation_rate`
- 이 확률이 *세대 진행에 따라 자동 감소*

| 세대 | 변이율 계산 | 100개 중 흔들리는 개수 |
|-----|-----------|-----------------------|
| t=0 (시작) | 0.35 - 0.25 × (0/50) = **0.35** | 약 35개 |
| t=25 (중간) | 0.35 - 0.25 × (25/50) = **0.225** | 약 22개 |
| t=50 (끝) | 0.35 - 0.25 × (50/50) = **0.10** | 약 10개 |

수식: `m(t) = 0.35 - 0.25 · (t/50)` — 처음 0.35에서 끝 0.10까지 *직선처럼 줄어듦*

#### (나) **흔들 때 얼마나 흔드냐** (정규분포 σ)
- 흔들 때는 무작위가 아니라 *정규분포(종 모양)* 로 흔듦
- 평균 0, 표준편차 σ = `(Max - Min) / 5` — 그 유전자의 *전체 범위의 1/5*
- 표준편차의 의미:
  - 68% 확률로 ±σ 안에서 흔들림
  - 95% 확률로 ±2σ 안
  - 99.7% 확률로 ±3σ 안

→ σ = range/5이면 *99.7% 확률로 범위의 ±60% 안에서 변형*. 즉 매우 큰 변형은 거의 안 일어남.

### 왜 처음엔 크게, 나중엔 작게?
- **초반**: 어디에 좋은 매스가 있는지 *모름* → 크게 흔들어 *넓게 탐색* (Exploration)
- **후반**: 좋은 영역이 *발견됨* → 작게 흔들어 *그 주변 미세조정* (Exploitation)

비유: 새 집 짓는 작업
- 처음엔 *망치·가위*로 큰 모양 잡기 (큰 변화)
- 나중엔 *핀셋·사포*로 디테일 다듬기 (작은 변화)

### 코드 한 줄씩 풀이
```python
def mutate(self, x, current_gen, total_gens=50):
    mutation_rate = 0.35 - 0.25 * (current_gen / total_gens)  # ① 현재 세대 변이율 계산
    if random.random() < mutation_rate:                       # ② 동전 던지기 (앞면이면)
        return x + random.gauss(0, 1/5)                       # ③ 정규분포로 흔듦
    else:
        return x                                              # ④ 뒷면이면 그대로
```

### 발표할 때 한 줄
> "변이율이 *세대마다 자동 감소* 합니다. 0.35에서 0.10까지 선형 감소이고, 흔들 때는 정규분포 σ=range/5로 흔들어요. 사람이 변이율을 조절할 필요 없이 *초반 탐색·후반 수렴*이 자동으로 됩니다."

## 🏁 슬라이드 5 — 토너먼트 선택 (Tournament, k=8)

### 한 줄 요약
> *부모를 어떻게 뽑냐 — 무작위로 8명 뽑고 그 중 1등을 부모로.*

### 단계별로
1. 한 섬에는 매스 15명이 살고 있음
2. 그 15명 중 *무작위로 8명* 뽑음 (`S = sample(island, 8)`)
3. 그 8명 중 *fitness가 가장 좋은 1명* 을 부모로 선정 (`argmin fitness(x), x ∈ S`)
4. 이 과정을 두 번 반복 → 부모 A, 부모 B 결정
5. 두 부모로 BLX-α 교배 + Gaussian 돌연변이 → 자식 1명

### `argmin` 이 뭐냐
- "최솟값을 만드는 x를 찾아라"
- `argmin_{x ∈ S} fitness(x)` = "S 안에서 fitness가 최소인 x를 반환"
- 여기서 *fitness가 최소 = 매스가 좋다* 는 뜻 (정렬 키가 (penalty, -score)라 작을수록 좋음)

### `fitness` 가 뭐냐
- 그냥 점수 하나가 아님. *튜플*: `(penalty, -score)`
- **penalty**: 법규 위반 정도 (BCR/FAR/높이/이격 위반 개수)
- **score**: 면적·일조 같은 목적함수 값
- *법규 위반 적은 매스* 가 무조건 우선, 위반 같으면 점수 좋은 매스 우선
- 즉 *법규 통과 매스 중에서 점수가 가장 좋은 1명* 이 부모

### 왜 8명?
| 토너먼트 크기 | 효과 |
|-------------|------|
| **2명** (너무 작음) | 약한 매스도 자주 부모가 됨 → 진화 느림 |
| **8명** (적당) | *상위 1/8 = 12.5%* 매스가 부모. 적당한 경쟁 강도 |
| **15명** (너무 큼) | 강한 매스만 항상 부모 → 다양성 사라짐 |

### 코드 한 줄씩 풀이
```python
def _tournament_select(self, island_population, k=8):
    # ① 무작위로 8명 뽑기
    candidates = random.sample(island_population, k)
    # ② 8명 중 (penalty 적고, score 좋은) 1등 선정
    return min(candidates, key=lambda c: (c.penalty, -c.score))
```

### 발표할 때 한 줄
> "운동회에서 무작위로 8명을 줄 세워 *1등을 부모로* 뽑는 방식입니다. 상위 12.5%가 부모 자격을 갖는 *적당한 경쟁 강도*예요."

## 🏝 슬라이드 6 — 5개 섬 + Steady-State + Ring Migration

### 한 줄 요약
> *75명 매스를 5개 섬에 분산시키고, 한 step에 1명만 교체하고, 10세대마다 우등생을 옆 섬으로 보낸다.*

이 슬라이드는 **세 가지 메커니즘이 합쳐진 것**이라 분리해서 봐야 이해됨.

---

### 메커니즘 ① — Island 모델 (5개 섬 분산)

**문제**: 매스 75명을 *한 그룹*에서 진화시키면?
- 우연히 강한 매스 1명이 자주 부모로 뽑힘
- 모든 자식이 그 매스 닮음 → 다음 세대도 마찬가지
- 결국 *모든 매스가 비슷해짐* (조기 수렴 = local optima 함정)

**해결**: 75명을 *5개 섬에 15명씩* 나눔
- 각 섬은 *독립적으로* 진화 (섬끼리 영향 X)
- 섬 1이 한 방향으로 수렴해도, 섬 2~5는 다른 방향 시도 중
- 결과적으로 *5개의 서로 다른 진화 경로가 동시 진행* → 다양성 보장

비유: 한 학교에 학생 75명. 한 반에 다 모아 공부시키면 모두 비슷한 답을 냄. 5반으로 나누면 각 반이 *독립적*으로 다른 방식 탐색.

---

### 메커니즘 ② — Steady-State 교체 (꼴찌 1명만 새로)

**일반 GA**: 한 세대 = 30명 부모 → 30명 자식 → 부모 *전부 갈아치움*
- 문제: 우연히 좋은 매스 1명이 *한 세대 만에 사라질 위험*

**Steady-State**: 한 step = *자식 1명만* 만들어 그 섬의 *worst 1명과 교체*
- 섬의 14명은 *그대로 유지*
- 꼴찌 1명만 새로
- *좋은 매스는 명시적으로 교체되기 전까지 영원히 살아남음*

비유: 한 반 15명 중 *꼴찌 1명만* 새 학생으로 바꾸기. 나머지 14명은 그대로 유지.

---

### 메커니즘 ③ — Ring Migration (10세대마다 우등생 이주)

섬을 *완전히 분리*하면 한 섬의 좋은 유전자가 다른 섬에 못 감. 그래서 *가끔* 이동.

**규칙**:
- 10세대마다 한 번씩
- 각 섬의 **best 2명** 을 *옆 섬*의 **worst 2명** 자리로 이주
- 옆 섬은 ring 구조 — 섬 0 → 섬 1 → 섬 2 → ... → 섬 4 → 섬 0

수식 `dst = islands[(i+1) mod 5]`:
- `i=0` → `dst = islands[1]` (섬 0의 best가 섬 1 worst 자리로)
- `i=1` → `dst = islands[2]`
- `i=2` → `dst = islands[3]`
- `i=3` → `dst = islands[4]`
- `i=4` → `dst = islands[(5) mod 5] = islands[0]` ← 다시 0으로 돌아옴 (ring)

`mod 5`의 의미: *5로 나눈 나머지*. (4+1) mod 5 = 5 mod 5 = 0 → 마지막 섬이 첫 섬으로 연결.

비유: 5개 반 학생들이 학기 10회마다 *우등생 2명씩 옆 반에 전학*. 1반 우등생 → 2반, 2반 우등생 → 3반, ..., 5반 우등생 → 1반.

---

### 전체 합쳐진 흐름 (50세대 진행)

| 세대 | 일어나는 일 |
|------|-----------|
| 0 | 5섬 × 15명 = 75명 무작위 생성 |
| 1 | 각 섬에서 자식 1명씩 만들어 worst 교체 (5명 새로) |
| 2 | 또 5명 새로 |
| ... | ... |
| 10 | **이주**: 각 섬 best 2명 → 옆 섬 worst 자리. 5섬 × 2명 = 10명 자리 교체 |
| 11~19 | 이주 안 함, 평소대로 |
| 20 | 두 번째 **이주** |
| ... | ... |
| 50 | 끝. 총 5번 이주, 250명 자식 생성 |

총 평가된 매스 수 = **75 (초기) + 50 × 5 (자식) = 325개**

### 코드 풀이
```python
class SSIEAJob:
    num_islands       = 5      # 섬 5개
    pop_per_island    = 15     # 섬당 15명
    max_gen           = 50     # 50세대
    migration_interval = 10    # 10세대마다 이주
    migrants_count    = 2      # 한 번에 2명씩 이주
    
    def _migrate(self):
        # 10세대마다 호출됨
        for i in range(5):
            dst = self.islands[(i + 1) % 5]              # 옆 섬 (ring)
            best_two = self.islands[i].get_best(2)       # 현재 섬 best 2명
            dst.replace_worst(best_two)                  # 옆 섬 worst 2명을 best 2명으로 교체
```

### 발표할 때 한 줄
> "75명을 *5개 섬*에 분산시켜 다양성을 보장하고, *Steady-state*로 한 step에 1명만 교체해 좋은 매스를 보존하고, *10세대마다 ring migration*으로 우등생을 옆 섬에 보내 좋은 유전자가 천천히 전체에 퍼지게 합니다. Nature Scientific Reports 2025 논문 기반이에요."

## 📊 슬라이드 7 — Pareto Front (사용자 결정)

### 한 줄 요약
> *50세대 후 결과는 단일 매스가 아니라 곡선. 어느 매스도 다른 매스를 모든 면에서 능가하지 못하는 매스들의 집합.*

### 비지배(non-dominated) 관계 — 구체 예시
세 매스의 점수표:

| 매스 | 면적 | 일조 |
|------|------|------|
| **A** | 80 | 30 |
| **B** | 50 | 70 |
| **C** | 70 | 25 |

- **A vs B**: A는 면적 우위, B는 일조 우위. *어느 쪽도 모든 면에서 이기지 못함* → **비지배 관계**
- **A vs C**: A 면적 80>70, A 일조 30>25 → *A가 모든 면에서 C보다 좋음* → A가 C를 **dominate**

→ A는 비지배 매스 (B에게 안 짐, C는 압도). C는 A에게 압도당함.

**Pareto Front = 자기를 dominate 하는 매스가 *하나도 없는* 매스들의 집합**

위 예시에서 PF = {A, B}. C는 제외.

### 수식 풀이
$$PF = \{x \mid \neg \exists y \text{ dominates } x\}$$

말로 풀면:
- `PF =` Pareto Front는
- `{x |` x들의 집합인데
- `¬∃y dominates x}` *x를 압도하는 y가 존재하지 않는* x

`¬` = "아니다", `∃` = "존재한다", 합치면 "*존재하지 않는다*".

### 50세대 후 실제 모습
325개 매스를 면적-일조 평면에 점으로 찍으면, 우상향 곡선이 그려짐. 그 곡선 위가 Pareto Front.

- 곡선 한쪽 끝 (면적 大, 일조 小) = **수익형** (면적 우선)
- 곡선 중간 (적당히 둘 다) = **균형형**
- 곡선 반대쪽 끝 (면적 小, 일조 大) = **환경형** (일조 우선)

### 핵심 철학 — 알고리즘은 결정 X
- 알고리즘은 *곡선만 그려줌*
- 어느 매스를 최종 선택할지는 *사용자(건축가)의 영역*
- 사업 목표가 면적이면 한쪽 끝, 일조면 반대쪽, 균형이면 중간 클릭
- *컴퓨터는 메뉴판을 차리고, 사람이 메뉴를 고른다*

이게 본 시스템의 가장 중요한 메시지:
**"단일 정답을 강요하지 않고, 사람이 판단할 *재료*를 자동 생성한다."**

### 코드 풀이
```python
def get_pareto_front(self, all_designs):
    return [
        x for x in all_designs                              # 모든 평가 매스 중에서
        if not any(                                          # 다음을 만족하는 y가 *없으면*
            y.dominates(x) for y in all_designs              #   y가 x를 압도
        )                                                    # 그런 x만 골라
    ]                                                        # list로 반환
```

핵심은 `not any(y.dominates(x) for y in all_designs)`:
- "x를 dominate하는 y가 *하나라도* 있으면 False"
- "*하나도* 없으면 True" → 그런 x만 PF에 포함

### 발표할 때 한 줄

## 💡 발표 시 안전 장치

각 슬라이드를 발표할 때 *수식·코드는 한 번 짚고 넘어가는* 정도로 충분. 청중이 자세히 보고 싶으면 *질문* 하니까. 본인은 그림(Visual Insight)으로 직관 잡고 *비유*로 풀이하면 자연스러움.

만약 막히면 → **"한 줄 요약"** 부분만 말하기:
- 3번: 부모 둘 사이 + 양 끝 1/3까지 무작위 자식
- 4번: 처음 크게 나중 작게, 자동 조정
- 5번: 8명 중 1등이 부모
- 6번: 5섬 + 꼴찌만 교체 + 우등생 이주
- 7번: 곡선만 그리고, 사용자가 선택

이 다섯 줄만 머리에 박혀 있으면 발표 못 망칩니다.
