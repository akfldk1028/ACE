## 3장 · 부모 둘에서 자식 매스 만들기 — 교배 (BLX-α)

### 본문
부모 두 매스의 *각 유전자*에 대해 — 단순 평균 X. 두 값 사이 거리 d만큼 *양 끝 1/3 확장*된 범위에서 무작위 샘플.

### ⭐ 구체 숫자 예시 (이게 핵심)
한 유전자(예: 박스 1의 x좌표)만 보자.

| 변수 | 값 |
|------|----|
| 부모 A의 x좌표 | **5** |
| 부모 B의 x좌표 | **8** |
| 거리 d = \|5 - 8\| | **3** |
| 양 끝 확장 폭 d/3 | **1** |
| 자식 가능 범위 | **[5-1, 8+1] = [4, 9]** |
| 자식 x좌표 | **Uniform(4, 9) → 무작위 6.7** (예시) |

→ 자식의 x좌표는 4와 9 사이 *어디든* 될 수 있음. *부모 둘이 못 가본 4미만이나 9초과*도 시도 X (범위 밖 클립).

29개 유전자 모두에 이 과정을 반복 → 자식 1명 완성.

### 코드
```python
def crossover(self, parent_a, parent_b):
    d = abs(parent_a - parent_b)        # 5와 8 → d=3
    return random.uniform(
        min(parent_a, parent_b) - d/3,  # 5 - 1 = 4
        max(parent_a, parent_b) + d/3   # 8 + 1 = 9
    )                                    # → Uniform(4, 9)
```

### 슬라이드 박스
- 헤드라인: **부모 둘에서 자식 매스 만들기**
- 부제: *교배 (Crossover, BLX-α)*
- Visual: 부모 A=5, 부모 B=8, 자식 가능 영역 [4, 9] 화살표
- 수식: `child = U(min - d/3, max + d/3)`
- **숫자 박스**:
  ```
  부모 A = 5,  부모 B = 8
  d = |5−8| = 3,  d/3 = 1
  자식 ∈ [5−1, 8+1] = [4, 9]
  → 무작위 자식 = 6.7
  ```

## 4장 · 처음엔 크게 흔들고, 나중엔 작게 — Adaptive Gaussian Mutation

### 본문
자식의 각 유전자에 대해 *동전 던지기*. 앞면 확률 = mutation_rate. 앞면이면 *정규분포*로 흔듦.

### ⭐ 구체 숫자 예시 — 변이율 자동 감소

| 세대 t | 변이율 m(t) = 0.35 − 0.25·(t/50) | 100개 중 흔들리는 개수 |
|-------|-----|-----|
| **0** (시작) | 0.35 − 0.25 × 0/50 = **0.35** | 35개 |
| **10** | 0.35 − 0.25 × 10/50 = **0.30** | 30개 |
| **25** (중간) | 0.35 − 0.25 × 25/50 = **0.225** | 22~23개 |
| **40** | 0.35 − 0.25 × 40/50 = **0.15** | 15개 |
| **50** (끝) | 0.35 − 0.25 × 50/50 = **0.10** | 10개 |

### ⭐ 구체 숫자 예시 — 정규분포 σ
한 유전자 범위가 [0, 10]이라면:
- σ = (10 − 0) / 5 = **2**
- 흔들 때 평균 0, 표준편차 2의 정규분포로 흔듦
- 99.7% 확률로 ±6 이내 변형

### 코드
```python
def mutate(self, x, current_gen, total_gens=50):
    mutation_rate = 0.35 - 0.25 * (current_gen / total_gens)
    if random.random() < mutation_rate:           # 동전 앞면
        return x + random.gauss(0, range/5)       # 정규분포로 흔듦
    else:
        return x                                   # 그대로
```

### 슬라이드 박스
- 헤드라인: **처음엔 크게 흔들고, 나중엔 작게**
- 부제: *돌연변이 (Adaptive Gaussian Mutation)*
- Visual: 파동 그래프 (왼쪽 큰 진폭 → 오른쪽 작은 진폭) + 망치/가위 → 핀셋/사포
- 수식: `m(t) = 0.35 − 0.25·(t/50)`, `σ = range/5`
- **숫자 박스**:
  ```
  t=0:   m=0.35  → 100개 중 35개 흔들림
  t=25:  m=0.225 → 100개 중 23개
  t=50:  m=0.10  → 100개 중 10개
  ```

## 5장 · 좋은 부모가 자주 뽑히기 — 토너먼트 선택 (k=8)

### 본문
한 섬에서 무작위로 8명 추출 → 그 중 *fitness 1등이 부모*. 두 번 반복해서 부모 A, B 결정.

### ⭐ 구체 숫자 예시
한 섬 15명 중 무작위로 8명 추출. 그 8명의 fitness 점수가 다음과 같다고 하자:

| 후보 | penalty (위반) | score (목적함수) | 부모 자격? |
|------|----|------|---|
| #3 | 2 | 80 | ❌ 위반 많음 |
| #7 | 0 | 65 | ✓ 후보 |
| #11 | 0 | 78 | ⭐ **선정** |
| #2 | 1 | 90 | ❌ 위반 있음 |
| #14 | 0 | 70 | ✓ 후보 |
| #5 | 0 | 55 | ✓ 후보 |
| #9 | 3 | 95 | ❌ 위반 최다 |
| #12 | 0 | 60 | ✓ 후보 |

→ penalty=0인 5명 중 score 최고는 #11 (78점). **#11이 부모로 선정**.

수치 환산: 8명 중 1등 = **상위 12.5% (= 1/8)**. 너무 적당한 경쟁 강도라 약한 매스도 가끔 부모가 되어 다양성 유지.

### 코드
```python
def _tournament_select(self, island_population, k=8):
    candidates = random.sample(island_population, k)
    return min(candidates, key=lambda c: (c.penalty, -c.score))
```

### 슬라이드 박스
- 헤드라인: **좋은 부모가 자주 뽑히기**
- 부제: *토너먼트 선택 (Tournament, k=8)*
- Visual: 운동회 트랙 8명, 1등에 별표
- 수식: `argmin_{x∈S} fitness(x), S = sample(island, 8)`
- **숫자 박스**:
  ```
  8명 추출 → 1등 = 상위 12.5%
  fitness key = (penalty, -score)
  → 법규 통과 매스 중 점수 최고
  ```

## 6장 · 5개 스터디 룸과 우등생 전학 — Island + Steady-State + Ring Migration

### 본문
세 가지 메커니즘 합체.
- **Island**: 75명을 5섬에 15명씩 분산 (조기 수렴 방지)
- **Steady-State**: 한 step에 자식 1명만 만들어 worst와 교체 (좋은 매스 보존)
- **Ring Migration**: 10세대마다 best 2명 → 옆 섬 worst 자리로 이주

### ⭐ 구체 숫자 예시 — 50세대 전체 흐름

| 시점 | 일어나는 일 | 누적 매스 평가 수 |
|------|----------|----------|
| t=0 | 5섬 × 15명 = **75명 무작위 생성** + 평가 | 75 |
| t=1 | 각 섬 자식 1명씩 = **5명 새로 평가** + worst 5명 교체 | 80 |
| t=2 | 또 5명 자식 | 85 |
| ... | | |
| **t=10** | 평소 5명 자식 + **이주 1차** (각 섬 best 2명 → 옆 섬 worst 2명 자리) | 130 |
| t=11~19 | 평소대로 | |
| **t=20** | 이주 2차 | |
| **t=30** | 이주 3차 | |
| **t=40** | 이주 4차 | |
| **t=50** | 이주 5차 + 종료 | **325** |

→ 총 평가 매스 = **75 (초기) + 50세대 × 5섬 = 75 + 250 = 325개**
→ 이주 횟수 = **50 / 10 = 5회**
→ 이주별 자리 교체 = **5섬 × 2명 = 10명 자리 교체**

### ⭐ 구체 숫자 예시 — Ring 구조
`dst = islands[(i + 1) mod 5]`

| i (현재 섬) | (i+1) mod 5 (목적지) |
|-----|-----|
| 0 | 1 |
| 1 | 2 |
| 2 | 3 |
| 3 | 4 |
| 4 | (5) mod 5 = **0** ← 처음으로 돌아옴 |

→ 0→1→2→3→4→0 ring 형태. 한 바퀴 돌면 원위치.

### 코드
```python
class SSIEAJob:
    num_islands       = 5
    pop_per_island    = 15
    max_gen           = 50
    migration_interval = 10
    migrants_count    = 2

    def _migrate(self):
        for i in range(5):
            dst = self.islands[(i + 1) % 5]            # ring
            best_two = self.islands[i].get_best(2)
            dst.replace_worst(best_two)
```

### 슬라이드 박스
- 헤드라인: **5개 스터디 룸과 우등생 전학**
- 부제: *Island + Steady-State + Ring Migration*
- Visual: 5섬 ring + 화살표 (best→worst)
- 수식: `dst = islands[(i+1) mod 5]`
- **숫자 박스**:
  ```
  75 = 5섬 × 15명
  50세대 × 5섬 자식 = 250명
  총 평가 = 75 + 250 = 325개
  이주 = 50/10 = 5회
  ```

## 7장 · 컴퓨터는 메뉴판을 차리고, 건축가가 고릅니다 — Pareto Front

### 본문
50세대 후 325개 매스 중 *비지배(non-dominated) 매스 집합* = Pareto Front. 알고리즘은 곡선만, 결정은 사용자.

### ⭐ 구체 숫자 예시 — 비지배 관계 직접 비교
세 매스의 점수:

| 매스 | 면적 | 일조 |
|------|------|------|
| **A** | 80 | 30 |
| **B** | 50 | 70 |
| **C** | 70 | 25 |

비교:
- **A vs B**: A 면적 80 > 50 (A 우위), A 일조 30 < 70 (B 우위) → *비지배 관계* (둘 다 PF 후보)
- **A vs C**: A 면적 80 > 70 ✓, A 일조 30 > 25 ✓ → **A가 C를 dominate** (C 탈락)
- **B vs C**: B 면적 50 < 70 (C 우위), B 일조 70 > 25 (B 우위) → 비지배 (둘 다 후보 — 단, C는 이미 A에 의해 탈락)

**결과: PF = {A, B}**. C는 제외.

### ⭐ 구체 숫자 예시 — 곡선 위 매스 분류
50세대 후 325개 중 PF에 약 30~50개가 들어감. 곡선 위:
- **수익형** (면적 90, 일조 20) — 곡선 한쪽 끝
- **균형형** (면적 65, 일조 50) — 곡선 중간
- **환경형** (면적 40, 일조 85) — 곡선 반대쪽 끝

사용자는 사업 목표에 따라 *곡선 위 한 점을 클릭*. 알고리즘은 곡선만 그리고 *결정 X*.

### 코드
```python
def get_pareto_front(self, all_designs):
    return [
        x for x in all_designs
        if not any(y.dominates(x) for y in all_designs)
    ]
```

### 슬라이드 박스
- 헤드라인: **컴퓨터는 메뉴판을 차리고, 건축가가 고릅니다**
- 부제: *Pareto Front + 사용자 결정*
- Visual: 면적-일조 평면에 곡선 + 매스 3종 (수익형/균형형/환경형) + 손가락
- 수식: `PF = {x | ¬∃y dominates x}`
- **숫자 박스**:
  ```
  A = (80, 30), B = (50, 70), C = (70, 25)
  A·B = 비지배,  A가 C를 dominate
  → PF = {A, B}, C 탈락
  ```
