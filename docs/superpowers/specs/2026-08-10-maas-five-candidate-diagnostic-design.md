# MAAS Five-Candidate Diagnostic Design

## Goal

Produce one fresh five-card PNG from five distinct persisted Codex/OAuth-authored MASS programs while running the normal BOOK, global Matrix4, legal/GFA, program, parking, clean-mesh, diversity-selection, and render flow. Make no paid LLM or VLM request and do not run or crop a target-20 board.

## Design

Extend the existing bounded diagnostic target set from `1, 2, 3, 20` to `1, 2, 3, 5, 20`. Target 5 uses all six BOOK scope labels because candidate count and scope search coverage are independent dimensions; its evaluation and candidate caps remain bounded at 60 and 20. It reuses the target-aware portfolio pair contract, wedge cap, law/program/parking gates, and five-card renderer without changing any acceptance threshold. Persisted OAuth manifests keep their admission SHA-256 and every admitted program hash mandatory. A replay shortlist validates the complete manifest first, then executes only admitted pre-BOOK hashes while preserving their original manifest ordinals.

The run is diagnostic evidence, not a publishable target-20 portfolio. It succeeds only if exactly five candidates survive and the generated PNG visibly contains five MASS cards. Machine evidence must report five unique admitted authored inputs and selected program/geometry identities, all five program hard passes, and five law/parking hard passes. Diversity is reported from the existing measured body phenotype, roof, chassis, plan, silhouette-distance, stepped, and wedge metrics; no label or manual crop may manufacture diversity.

## Files and boundaries

- `ARR/backend/design/maas/book_language/portfolio_benchmark.py`: admit diagnostic target 5 through the existing generic bounded-budget path.
- `ARR/backend/design/management/commands/benchmark_maas_book_program_portfolios.py`: expose `--diagnostic-target 5` in the CLI.
- `ARR/backend/design/test_maas_book_language.py`: prove target 5 is accepted and bounded while unsupported targets still fail.
- Existing C89 and C100 manifest/admission pairs: read-only inputs.
- New C105-C107 output directories: generated evidence only.

## Failure behavior

If fewer than five candidates survive, preserve the partial board and typed deficits and report failure honestly. Do not loosen law, capacity, parking, identity, pair-distance, stepped, or wedge gates; do not request new provider output; do not substitute deterministic geometry.
