# MAAS Three Architecture Languages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce one honest three-card ISO PNG from three site-feasible, materially different authored architectural MASS languages through the current production gates.

**Architecture:** Keep the C124 continuous-fold program as the verified first island. Author two additional typed ASTs from different topology/section islands, reject them cheaply unless clean compilation and the exact four-band affine selector can reach the `0.60` capacity budget, then admit all three in one immutable Codex/OAuth manifest and run `--diagnostic-target 3`. Final diversity is decided from certified mesh metrics and direct inspection of the shared ISO board.

**Tech Stack:** Django management command, typed GeometryProgram AST, Manifold3D, Shapely/GEOS, NumPy Matrix4 affine placement, existing BOOK/law/parking/semantic/portfolio gates.

## Global Constraints

- Preserve exactly one canonical UnitBox authority per program; additional typed profile/cutter primitives are operands in the same DAG.
- Preserve BaseVolume, one global Matrix4 placement, typed BOOK composition and final authored-surface identity.
- Capacity utilization hard minimum is `0.60`; `0.70` is preferred. Direct affine acceptance remains `0.995` of each candidate's requested budget.
- Do not restore host-replacement CSG, legal stair synthesis, per-floor recentering or independent floor scaling.
- Do not use camera changes, labels or parameter-only clones as diversity evidence. All three cards use the same ISO renderer.
- No paid LLM/VLM call and no target-20 run.
- A partial board is failure evidence; never claim `3/3` unless exactly three compatible candidates survive.
