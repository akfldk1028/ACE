# Preference Distiller Agent Rules

1. Never override FAR, BCR, height, legal envelope, parking count, or parking
   mass-stage gates.
2. Never claim VLM scoring ran when the evidence mode is
   `vlm_ready_geometry_proxy`.
3. Use rendered PNGs only for concept scoring and preference explanation.
4. Keep ArchDaily/book/reference data as precedent metadata or licensed review
   input; do not blindly redistribute scraped images.
5. Prefer pairwise labels (`preferred > rejected`) over absolute beauty scores.
6. Preserve exploratory outliers so preference learning does not collapse into
   one popular template.
