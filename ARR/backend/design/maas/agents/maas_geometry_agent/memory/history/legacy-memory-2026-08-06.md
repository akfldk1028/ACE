## 2026-08-06 - 4x4 contract and context-faithful preflight correction

- The global `Matrix4` is authored data attached to one LLM-authored
  BaseVolume. It establishes that AST's normalized coordinate frame and pose;
  it is not a deterministic mass generator and may not encode a shared
  morphology recipe.
- Numeric section controls inside one persisted LLM-authored AST are authored
  design decisions. Runtime code may validate them, but it must not manufacture
  common `z` breakpoints from legal floors, copy those controls into other
  candidates, or disguise the same recipe with epsilon changes.
- The static-AST preflight must pass the same `program_reference_contract`,
  dimensional context, operator-depth limit, and downstream rule reserve used
  by production. Context-free parser success is invalid evidence. The earlier
  folded `profiled_hall` diagnostic was therefore downgraded: neighborhood
  production correctly rejects that macro.
- Resolve that contract with the canonical `program_id` (for example,
  `neighborhood_living`), never the localized display label stored in a report.
  The display label may resolve to the generic profile and falsely admit
  macros or omit required access-bound relations.
- Only direct, independently persisted Codex/OAuth AST fragments may enter the
  static manifest. Packaging may attach admission and hashes but may not loop,
  sweep, template, or derive morphology. Rejected fragments remain evidence;
  they are never silently repaired by deterministic fallback.
- UnitBox lineage means exactly one canonical `box(1,1,1)` begins the authored
  BaseVolume chain. It does **not** mean the entire AST may contain only one
  primitive: typed wedge/box/polygon operands used as authored cutters or
  composition bodies remain legal. The unchanged-authored-solid certifier must
  validate the canonical UnitBox separately from these typed operands. The
  floorwise CSG path keeps its narrower single-primitive precondition because
  it is a different, explicitly stepped-only authority.
- The author prompt must never claim that coordinates are unavailable while
  embedding raw parcel/legal GeoJSON elsewhere in the same JSON. Convert the
  law field to a coordinate-free, generation-host principal frame: normalized
  long/short bounds, centroid drift, and area ratios. This is constraint
  context only; the prompt must explicitly forbid replaying band boundaries or
  copying a floorwise profile into the AST.
- A bounded BOOK offer is acceptable per provider request, but repeated author
  batches must rotate across the complete 13,662 executable paths. Its offer
  identity therefore includes batch index/count, variation offset, legal-fit
  feedback, capacity/family deficits, and supply evidence. Every compact path
  record retains the complete authored UnitBox Matrix4 contract and variation
  state, not merely `matrix4_count=1`.
- A static Codex/OAuth manifest must bind each selected path to the exact
  bounded offer seen by that individual LLM response. Persist the ordered offer
  path IDs, their canonical SHA-256, prompt SHA-256, and direct response ID in
  the binding. Production admission fails closed when the selected path is not
  a member. Merely proving that a path exists somewhere in the 13,662-path
  lattice is insufficient and permits hardcoded path injection.
- Treat the maximum-FAR legal field as a reusable invisible constraint
  container, never as authored or visible MASS morphology. For convex floor
  containers, exact containment of every projected mesh triangle is equivalent
  to testing all transformed triangle vertices against the container's edge
  half-spaces. Use the vectorized Matrix4/half-space path during bounded pose
  search. For concave containers, batch transformed triangles through GEOS
  `covers` directly; containment of their union is equivalent to containment of
  every member triangle, so repeated `unary_union` is still unnecessary. Keep
  exact CSG only for the final shortlisted certificate.

## CURRENT GOAL AND AUTHORITY — 2026-08-06

This section is the first authority for all new MASS work. Later dated
corrections refine it. Older run notes are historical evidence and may not be
reactivated when they conflict with this goal.

### Goal

Produce one verified competition portfolio of exactly twenty MASS alternatives
by selecting from the large executable BOOK composition graph, not by writing a
twenty-item template list. Every selected alternative must be directly
LLM/Codex-OAuth-authored as a persisted typed AST, retain
`UnitBox -> BaseVolume -> global 4x4 Matrix4 -> ordered BOOK graph operations -> CSG`
lineage, pass the same production BOOK/program/legal/parking/mesh/capacity path,
use zero pose or geometry fallback, achieve final measured capacity utilization
`>= 0.70`, and remain materially different in the final certified combined PNG
and frontend graph view.

### Architectural authorship model

- The source of diversity is the complete BOOK composition lattice: six
  BaseVolume fractions x three orientations x thirty operative semantics x
  bounded variations x valid combination edges x aggregation methods x
  case-study relation paths. This is a search population of thousands of
  executable graph paths.
- The LLM receives this graph, program/site context, and measured failure
  feedback. It authors and ranks executable AST paths from the population.
  Twenty is the final selected set, never a manually assigned list of twenty
  recipes and never one required operator per output.
- No operative is globally mandatory. In particular, taper, step, shear,
  courtyard, bridge, or any other single mechanism may not be forced across the
  portfolio as a shortcut for law, capacity, count, or diversity.
- Deterministic code may expand typed graph possibilities and calculate
  legality, parking, capacity, topology, hashes, and distances. It may not
  invent the architecture, substitute a generic form, relabel fallback as LLM
  authorship, or introduce morphology anchors to fill the count.

### Projection and selection model

- Visible legal projection preserves the authored mesh through one global pose
  and a continuous legal-envelope intersection. Separately extruded floor-band
  masks and capacity-derived section-loft replacement are forbidden because
  they collapse different graph paths into the same staircase.
- Exact law-derived floor plates remain GFA/capacity measurement authority; the
  continuous visible envelope does not rewrite those plates. Visible-form
  authority and capacity-measurement authority are bound but distinct.
- Diversity is a two-stage hard contract: compositional graph/topology distance
  before BOOK and certified visible-mesh/silhouette distance after all legal
  projection. Failure at either stage triggers LLM replenishment from
  underrepresented graph regions.
- Completion requires twenty trusted LLM-authored selected candidates, all hard
  gates passed, one directly inspected combined PNG showing genuine variety,
  machine-readable completion evidence, and the frontend graph/portfolio view.
  A partial diagnostic, source-only validator, or attractive pre-projection AST
  is not goal achievement.

### Superseded historical tactics

- Target3 deterministic morphology anchors are debugging history only and are
  forbidden in LLM-only or final portfolio selection.
- Hand-authored family tables, profiled-prism catalogs, one-language-per-output
  quotas, and a repeated taper/step recipe are not the portfolio generator.
- Any older statement allowing partial fallback, reduced diversity, source-only
  acceptance, or legal/parking success below capacity `0.70` is superseded.
