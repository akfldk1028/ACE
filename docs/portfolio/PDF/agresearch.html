01 · Problem

Termination Regret

Multi-agent LLM systems (AutoGen, LangGraph, CrewAI) commonly use a fixed max_turns=10 across all topologies. But a 2-agent chain and a 4-agent debate have fundamentally different convergence behaviors. Applying a uniform stop rule produces what we term termination regret — three failure modes:

Over-termination

Debate team continues 4 rounds past consensus, burning tokens with zero quality gain.

Under-termination

Sequential pipeline stops after the draft stage, never reaching the refinement that would have caught factual errors.

Topology mismatch

Selector-based team applies max-turn calibrated for flat patterns, cutting routing agent off mid-deliberation.

F3 — Semantic Convergence Exp03 · Sentence-BERT

Figure 6. Semantic stability per turn (Sentence-BERT cosine). Pipe 32% > B1 26% > A 16% > B2 12% > C 0%. Debate-3 has highest cosine (0.673) but never converges — every turn introduces new arguments. Convergence signals are topology-dependent; one-size-fits-all detection fails.
Engineering takeaway: Convergence-based termination only viable for Pipeline / B1 / A. For B2 / Debate, use topology-specific signals (turn loop detection, argument novelty score).

F4 — ΔU Negative Result Exp05 · 800 runs

Figure 8. Pareto frontier — quality vs cost. Solo dominates lower-left. Refl-2 anchors high-quality region. Debate / MoA fall off frontier.
Figure 8b. ΔU adaptive vs keyword baseline. Swm-4: −70% (only success). Refl-2: +258% overhead. RR-3 +32%, Sel-3 +63%.
Negative result with practical value: 7 of 8 patterns: keyword TERMINATE is near-optimal. ΔU(t) = ΔQ(t) − λ·ΔC(t) is a diagnostic lens, not a replacement. Hybrid strategy: keyword everywhere, ΔU only for B2 (decentralized handoff) where keyword fails (28% success rate).

F5 — Cost Prediction Model Exp06 · 718 runs · 5-fold CV

Figure 9. Random Forest feature importance. R² = 0.54 on 5-fold CV. Top features: task_technical (0.27) · pat_D (0.17) · agent_count × max_messages (0.16). The interaction term — not raw count — emerges as the strongest topology signal.
Honest boundary: Topology features alone explain 54% of cost variance. The remaining 46% is task-content complexity — not predictable from coordination structure. Holdout on Exp05 task suite: R²=0.29 (recalibration needed across task domains).

F6 — Difficulty Dominates Pattern Exp07 · 669 runs · 5 LLMs

Figure 10. Quality by difficulty × pattern across 5 models. Difficulty effect η²=0.363 (large) vs pattern effect η²=0.039 — 9.3× difference. Solo dominates Easy & Hard. Refl-2 helps only Haiku & GPT-5.4 at Medium (Cohen's d=1.26 / 1.83).
Recommendation matrix: Solo as default for cost-efficiency. Activate multi-agent coordination only when task difficulty approaches the model's capability frontier. The previously-reported inverted-U pattern holds for only 1 of 5 models (Haiku). Capability-aware topology selection beats blanket multi-agent strategies.

04 · Contributions

Seven Contributions

1 · Cross-topology study

First systematic comparison of 13 patterns × 7 experiments × 2,200+ runs in unified AutoGen framework. Prior work: 1-3 patterns max.

2 · Termination regret metric

Post-hoc G-Eval trajectory analysis identifies optimal stop point vs actual stop point. Quantifies systematic over-/under-computation.

3 · Claim-level convergence

Sentence-BERT semantic stability extending Hu NeurIPS 2025 KS-test to all 13 topologies. Shows convergence is topology-dependent.

4 · Pattern-specific error taxonomy

Aligned with MAST (Cemri 2025): topology-correlated error types (token overflow / turn loop / missing keyword) per pattern.

5 · ΔU diagnostic framework

Negative result: 7/8 keyword optimal. Positive result: B2 −70% with ΔU. Marginal utility as principled diagnostic lens, not optimizer.

6 · Cost prediction model

RF R² = 0.54 · agents × max_messages strongest predictor · 46% task-content boundary acknowledged.

7 · Difficulty-aware recommendation matrix

5 LLMs × 3 difficulty levels mapping. Solo dominates cost-efficiency at every level. Refl-2 helps only weak models at medium difficulty (capability moderation).

"Termination strategy should be a first-class design decision."

Framework released — 13 pattern implementations · 7 experiment runners · analysis scripts.
