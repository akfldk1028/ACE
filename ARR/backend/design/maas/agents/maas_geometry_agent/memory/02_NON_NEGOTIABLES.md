# Non-negotiables

- deterministic morphology fallback is forbidden;
- no law floor/Z breakpoint, taper/pivot/section ratio, parcel coordinate,
  precedent outline, or exact-fit recipe may be hardcoded into production;
- no template tables, parameter sweeps, morphology anchors, or renamed copies;
- the LLM authors topology, operators, parameters, and one global Matrix4;
- deterministic code owns law, parking, GFA/FAR, capacity, mesh and diversity;
- law-derived floor boundaries may not be replayed as visible AST sections;
- Qatar National Library and other references provide transferable spatial
  capabilities, never a completed silhouette to copy;
- a failure is discarded unchanged and becomes measured feedback only;
- no threshold weakening is permitted to manufacture a count of twenty.
