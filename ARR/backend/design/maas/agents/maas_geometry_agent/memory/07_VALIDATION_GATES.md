# Validation gates

Every candidate proceeds sequentially:

1. assert one shared request count drives LLM target count, BOOK offer slice,
   parser expected count, and batch count; apply measured retry-family bans,
   then parser and program contract;
2. source compile, one UnitBox, one global Matrix4, connected watertight mesh;
3. exact selected BOOK projection and compile;
4. try the unchanged-solid affine selector as a cheap fast path;
5. when that selector is null, continue through the production
   `materialize_floorwise_legal_source` authority: preserve the authored mesh,
   apply one fixed-pose site Matrix4, and intersect it with the continuous
   legal envelope; selector null alone is never a terminal rejection;
6. require either path to produce a connected, watertight, contained visual
   mesh and measured capacity utilization >= 0.70;
7. only then freeze/package and invoke canonical validation exactly once;
8. law, parking, final mesh, authored-identity and diversity certification.

Legal CSG permission and pose search are separate authorities. Legal clipping
may scale the fixed authored pose to capacity, but may not activate a coded
angle/aspect ladder or reauthor orientation, proportion, section profile, or
morphology. The normalized authored mesh must reach the single site-fit stage
without a prior host-fit transform; two successive site fits are forbidden.

The sentence “compiler-only preflight is not legal preflight” is a hard harness
rule. No source/BOOK compiler result may be labelled legal-fit evidence.
The production author parser must reject every parameter name absent from the
operator contract; compiler defaults may never hide an LLM key error.
It must also enforce numeric minima/maxima, string enums, and numeric-vector
lengths before compilation. These are global AST admission rules, never
candidate-specific geometry recipes.
Measured retry feedback may temporarily name forbidden body-rule families or
individual operators. The same production parser must enforce those bans
before source compilation and remove them when the measured retry window ends.
