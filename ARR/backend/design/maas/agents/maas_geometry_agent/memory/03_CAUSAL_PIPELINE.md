# Causal pipeline

The only accepted order is:

`UnitBox -> authored base-form capability -> one global 4x4 Matrix4 -> BOOK p.3 BaseVolume fraction -> orientation -> ordered BOOK graph operations -> typed CSG -> production legal/capacity projection -> parking/mesh/diversity -> PNG/frontend`

The BOOK offer is prepared before the LLM call. The LLM selects an exact offer
and authors the AST against it. Geometry is materialized only after the response.
Compiler success is structural evidence, not legal or capacity evidence.
