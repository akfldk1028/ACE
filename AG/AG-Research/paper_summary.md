## 1. 연구 동기 (Why)

### 핵심 문제
LLM 멀티 에이전트 시스템이 급속 확산되고 있으나, **"언제 멈출 것인가"**는 체계적으로 연구되지 않았다.

현재 종료 기준:
- 고정 턴 수 (max_turns=10)
- 키워드 감지 ("TERMINATE")
- 외부 타임아웃

**문제점**: 에이전트 조정 방식(토폴로지)과 무관하게 동일 기준을 적용 → **종료 후회(termination regret)** 발생

| 시나리오 | 문제 | 비용 |
|----------|------|------|
| 과잉 종료 | 합의 후에도 토론 계속 | 토큰 낭비 |
| 과소 종료 | 정제 단계 전에 중단 | 품질 손실 |
| 토폴로지 불일치 | 선택자 라우팅 중 강제 종료 | 기능 손실 |

### 왜 지금?
- Hu et al. (NeurIPS 2025): debate 전용 종료만 다룸
- REFRAIN (2025): 단일 에이전트 CoT 전용
- Aegean (2025): 병렬 합의 전용
- **다양한 토폴로지를 통합 비교한 연구 = 없음** ← 우리의 기회

## 2. 핵심 기여 (What)

### 차별점 한 줄 요약
> 14개 토폴로지를 **동일 프레임워크·동일 모델·동일 과제**로 체계 비교하고, **한계효용 진단 프레임워크(ΔU(t) = ΔQ(t) - λ·ΔC(t) → 0)**로 종료 효율을 분석하는 **최초의** 연구

### 6대 기여
1. **교차 토폴로지 종료 비교** - 14패턴, 6범주(S/A/B1/B2/C/D), 1프레임워크
2. **Solo baseline 도입** - 단일 에이전트 하한선 설정 (범주 S), 멀티 에이전트 부가 가치 정량화
3. **종료 후회 지표** - G-Eval 턴별 품질 궤적으로 최적 vs. 실제 종료 시점 비교
4. **B1/B2 토폴로지 분해** - 중앙 라우팅(Star)과 분산 핸드오프(Mesh)의 정반대 스케일링 규명
5. **한계효용 진단 프레임워크** - ΔU(t) = ΔQ(t) - λ·ΔC(t), 기존 keyword 종료의 적합성 진단 도구 (7/8 패턴 근최적 확인, swm4 예외 식별)
6. **교차 모델 검증** - GPT-4o-mini 125회 실행, Spearman ρ=0.900으로 효율 순위 일반화 확인

## 5. 핵심 수식 (논문의 오리지널 기여)

### 한계효용 기반 진단 프레임워크
$$\Delta U(t) = \Delta Q(t) - \lambda \cdot \Delta C(t)$$

- $\Delta Q(t) = Q(t) - Q(t-1)$: 턴별 품질 증분 (플래토 시 0에 수렴)
- $\Delta C(t)$: 턴별 한계 비용 (대략 일정)
- **진단 조건**: $\Delta U(t) \leq 0$ → keyword 종료가 적시인지 판별
- **핵심 위치**: ΔU는 keyword 종료의 **"대체"가 아닌 "진단 도구"**
  - 7/8 패턴에서 keyword가 근최적 = **기존 관행 검증**
  - swm4가 예외 = **ΔU의 진단 가치** (keyword로는 과잉 종료 발생)
  - ⚠️ **하이브리드(keyword+ΔU) 구현/검증은 미수행** → 향후 필수 과제

### 비용 분해 (심사 방어용)
$$C(t) = C_{agents}(t) + C_{coord}(t)$$

- $C_{coord}$: 라우팅 결정 비용 (B1에서만 존재, B2는 에이전트 비용에 흡수)
- B1 vs B2 분해로 "조정자 오버헤드 세금 vs 핸드오프 폭증" 정량화

### REFRAIN/Aegean과의 차이
| | REFRAIN | Aegean | **본 연구** |
|--|---------|--------|-----------|
| 대상 | 단일 에이전트 CoT | 병렬 합의 | **14개 토폴로지, 6범주** |
| 방법 | 판별기+UCB | 쿼럼 감지 | **한계효용 ΔU(t) 진단** |
| λ | 고정 | 해당없음 | **λ-비감응 (ΔQ 포화 지배적)** |
| 기준선 | 없음 | 없음 | **Solo baseline 포함** |

| W4 | **n=5 교차 모델 상관** | 중간 | 중간 | 13패턴으로 확장 + GPT-4o 추가 |
| W5 | **하이브리드 미검증** | 높음 | 높음 | 하이브리드 조건 구현 + 실험 |
| W6 | **신뢰구간 부재** | 중간 | 높음 | std 계산 + CI 추가 (스크립트만) |
| W7 | **Finding 39개 과다** | 중간 | 높음 | 핵심 15개로 압축, 나머지 부록 |
| W8 | **단일 인간 평가자** | 높음 | 중간 | 제2 평가자 섭외 + κ 보고 |
| W9 | **Venue fit (COLM)** | 높음 | 높음 | AAMAS 우선 검토 |

**총평**: 데이터(2000+ runs)는 충분. 핵심 기여(14 토폴로지 체계 비교, B1/B2 분리)는 유효. 그러나 ΔU 프레임워크의 실용적 효과가 약하고, 평가 신뢰도가 top-venue 기준 미달. W1+W2+W5 해결 시 AAMAS 수준 충분, W1~W8 전체 해결 시 EMNLP/NeurIPS 수준 가능.
