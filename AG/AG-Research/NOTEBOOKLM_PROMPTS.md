```
이 논문을 기반으로 연구 발표용 PPT 슬라이드를 만들어줘.

## 필수 조건
- 한국어
- 흰색 배경
- 각 슬라이드: 제목 + 핵심 포인트 3~4개 + 발표자 노트(대본)
- 모든 수치는 소스 문서의 실제 데이터 사용 (반올림/추정 금지)
- 차트가 지정된 슬라이드는 반드시 해당 차트 포함

## 슬라이드 구성 (15장)

### 슬라이드 1: 제목
- 논문 제목: "멀티 에이전트 팀은 언제 멈춰야 하는가?"
- 부제: 14가지 협력 토폴로지의 종료 역학 체계적 연구
- 2,000회+ 실험, AutoGen + Claude Haiku 4.5

### 슬라이드 2: 연구 동기
- 핵심 질문: "이 팀, 언제 멈춰야 하나요?"
- 현재 방법 3가지 (max턴, TERMINATE 키워드, 타이머)의 문제점
- 종료 후회(termination regret) 개념: 과잉 종료 / 과소 종료 / 토폴로지 불일치
- 발표자 노트: 2명 사실확인 팀 vs 4명 토론 팀에 같은 "10턴" 한도를 거는 예시

### 슬라이드 3: 선행 연구 갭
- Hu et al. (NeurIPS 2025): 토론 패턴만
- REFRAIN (2025): 단일 에이전트만
- Aegean (2025): 병렬 합의만
- 이 연구: 14패턴 x 6범주 x 동일 프레임워크 = 최초

### 슬라이드 4: 14개 패턴 분류 다이어그램
- 차트: 6범주 트리 다이어그램 또는 분류표
  - S: Solo (1명)
  - A: RR-2/3/4 (고정 순차)
  - B1: Sel-3/4 (중앙 라우팅) — 중앙 조정자가 분배
  - B2: Swm-3/4 (분산 핸드오프) — 자율 P2P 핸드오프
  - C: Refl-2/3, Debate-3/4 (구조화 피드백)
  - D: Pipeline, MoA (복합 구조)
- B1 vs B2 분리 근거: 스케일링이 정반대 (준선형 vs 초선형)

### 슬라이드 5: 실험 설계 개요
- 5개 실험 (효율, 품질, 수렴, 오류, 적응적 종료)
- 25개 과제 x 9개 도메인 (과학, CS, 역사, 철학, 법, 게임, 공학, 경영, 의학)
- 4가지 과제 유형: 사실/분석/기술/창의
- 에이전트 모델: Claude Haiku 4.5, 평가: Claude Sonnet 4.5 (G-Eval)

### 슬라이드 6: Exp01 — 비용 랭킹
- 차트: 수평 막대 그래프 (차트 5 데이터 사용)
  - Solo(1,287) → swm3(4,341) → refl2(5,281) → ... → pipe(13,186)
  - Solo 대비 3.4배 ~ 10.2배
- 새로운 비용 위계: A ≈ B2 < B1 ≈ C ≪ D
- 핵심: swm3(3명)이 rr2(2명)보다 12% 저렴

### 슬라이드 7: Exp01 — B1 vs B2 정반대 스케일링
- 차트: 이중 비교 막대 그래프 (차트 3 데이터 사용)
  - sel3→sel4: 토큰 1.28x, 턴 1.14x (준선형, 안정)
  - swm3→swm4: 토큰 3.37x, 턴 3.02x (초선형, 폭발)
- 턴당 토큰: B1=2,270~2,538 (긴 독백) vs B2=523~544 (짧은 핸드오프)
- 같은 "라우팅"이지만 완전히 다른 대화 패턴

### 슬라이드 8: Exp01 — 도메인별 분석
- 차트: 히트맵 (차트 2 데이터 사용, 9도메인 x 8패턴)
- debate3만 도메인 불변 (CV=0.14)
- swm3는 역사(1,384) vs 경영(9,163)으로 도메인 민감 (CV=0.67)
- 의학에서 pipe가 29,621 토큰으로 폭발

### 슬라이드 9: Exp02 — 품질 궤적 3가지
- 차트: 3개 소형 꺾은선 그래프 (턴별 품질 점수)
  - 패턴1 단조증가-고원: RR-3 (3.9→4.5→4.1→4.1)
  - 패턴2 2턴 정점: Refl-2 (3.9→4.8→4.0)
  - 패턴3 단조 하락: Debate-3 (3.8→3.4→3.3)
- 종료 후회: Refl-2=0.6턴(품질손실 0.00) vs Debate-3=2.0턴(품질손실 0.65)
- Refl-2의 APPROVED 키워드가 완벽한 자연 종료 신호

### 슬라이드 10: Exp03 — 의미 수렴
- 차트: 막대 그래프 (차트 8 데이터, 수렴율 %)
  - pipe(32%) > sel4(28%) > sel3(24%) > rr3(16%) > swm4(16%) > swm3(8%)
  - debate3(0%), refl2(0%)
- 피드백 패턴은 의미적으로 수렴하지 않음 → 품질 기반 종료 필요
- Sentence-BERT (all-MiniLM-L6-v2, 384차원), 임계값 0.85

### 슬라이드 11: Exp04 — 오류 분석
- 차트: 막대 그래프 (차트 7 데이터, 오류율 %)
  - swm4만 76%, swm3 11.1%, 나머지 전부 0%
- 3가지 실패 유형: 맥락 폭발(A) / 턴 폭발(B2) / 키워드 실종(MoA)
- 과제 유형별: factual=0% vs technical=33→53→100% (팀 커질수록 위험)

### 슬라이드 12: Exp05 — ΔU 한계 효용 공식
- 수식: ΔU(t) = ΔQ(t) - λ·ΔC(t)
  - ΔQ(t): 품질 증분, ΔC(t): 비용(킬로토큰), λ: 균형 파라미터
  - ΔU(t) ≤ 0 → 종료 신호
- 차트: 패턴별 수렴 턴 막대 그래프 (차트 1 데이터)
  - swm3=1.1턴, refl2=2.0턴, rr3=2.4턴
  - λ 값에 둔감 (0.0→0.5 변경해도 0.1턴 차이)
- 핵심: 품질 포화(ΔQ≈0)가 수렴의 주된 원인

### 슬라이드 13: Exp05 — ΔU의 역설적 결과
- 차트: 비교 표 (기준선 vs 적응적 토큰 변화)
  - 7/8 패턴에서 ΔU 적용 시 오히려 비용 증가 (+8%~+258%)
  - swm4에서만 -70% 토큰 절감 (극적 개선)
- 결론: TERMINATE 키워드가 7/8 패턴에서 거의 최적
- ΔU는 키워드가 실패하는 swm4의 보조 수단

### 슬라이드 14: 교차 모델 검증 + 한계점
- GPT-4o-mini: Spearman ρ=0.900 (p=0.037), 상대적 순서 보존
- 한계점:
  - κ=0.244 (평가자 간 일치도 약함)
  - 교차 모델 n=5 (표본 작음)
  - 하이브리드(키워드+ΔU) 미검증
  - 단일 프레임워크(AutoGen), 단일 과제 유형(open-ended Q&A)
  - 2~5명 팀만 (10명+ 미확인)

### 슬라이드 15: 실무 가이드라인 + 핵심 기여
- 가이드라인 표:
  - 비용 최소화 → Swm-3 또는 Refl-2
  - 최고 품질 → Refl-2 (4.80/5.0)
  - 예측 가능한 비용 → Debate-3 (CV=0.14)
  - 대규모 팀 → B1(Sel) 사용 (B2 위험)
- 핵심 기여 한줄: "토폴로지가 종료를 결정한다. 에이전트 수가 아니라 연결 방식이 핵심."
```
