# Latest 20 MASS Board Design

Updated: 2026-07-30 KST

## Goal

Produce one deterministic PNG containing twenty materially different,
LLM-authored MASS candidates without paid provider calls, while preserving
truthful per-candidate validation status.

## Scope

The first deliverable is a diagnostic choice pool, not twenty accepted
buildings. Every card must state `PRE-LEGAL / NOT EVALUATED` until the existing
real-PNU law, capacity, floor, parking, authored-identity, and VLM stages have
evaluated that exact program and geometry identity.

The implementation must not weaken any hard gate or claim that a theoretical
operator-combination count was actually searched.

## Candidate supply

Read accepted `arr.maas.geometry_llm_author_cache.v3` files from an explicitly
provided cache directory. Collect exact `compiled_programs`, deduplicate by
`program_hash`, and select a deterministic diverse prefix. Rejected caches,
recipe fixtures, malformed programs, and named-family selectors are excluded.

All programs are normalized to the canonical `1/1 UnitBox` BaseVolume before
compilation. Family names remain post-hoc morphology labels only.

## Output

Reuse `generate_maas_creative_100` persistence and deterministic rendering:

- twenty individual four-view candidate PNGs;
- twenty candidate JSON records with program and geometry hashes;
- one `maas-creative-board.png` contact sheet;
- one portfolio JSON and research bundle per MASS;
- zero paid LLM, image, or VLM calls.

The board uses a 5-column by 4-row layout for a twenty-candidate review. Its
header and card labels must make the `PRE-LEGAL / NOT EVALUATED` status clear.

## Failure behavior

Fail closed when the cache directory is missing, fewer than the requested
number of unique compilable programs exist, or any selected program is not a
valid exact `GeometryProgram`. Never fall back to recipes.

## Follow-on legal evaluation

The board is the visible supply checkpoint. A later execution phase routes
the exact selected identities through existing real-PNU law, capacity, floor,
parking, authored-projection, and VLM gates. Rejected candidates remain
visible as diagnostic evidence rather than disappearing.
