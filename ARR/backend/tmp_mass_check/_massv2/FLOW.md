# 매스 플로우 — 이것 말고 다른 순서는 없다

이 파일이 정본이다. 단계를 손으로 부르지 말 것. 손으로 부르면 뒤쪽이 빠진다 —
2026-09-04에 세 라운드 연속으로 BOOK 탐색, develop 되먹임, 브리프 되먹임이
빠졌다. 아무도 빼기로 결정하지 않았다. 사람이 명령을 하나씩 타이핑했을 뿐이다.

## 한 명령

```
cd D:/Data/25_ACE/agents/MassAgent
bash skills/mass-cycle/scripts/cycle.sh <라운드명> [문장수]
bash skills/mass-cycle/scripts/cycle.sh <라운드명> --from=8   # 중간부터 재개
```

어느 단계든 실패하면 사이클이 거기서 멈추고 로그에 남는다. 발행만 하지 않는다 —
사람이 보고 있는 시트를 덮어쓰지 않기 위해서다.

## 반드시 같이 도는 다섯

1. **LLM 저작** — 문장을 쓴다
2. **BOOK 탐색** — `generate_maas_creative_100`, 카탈로그 134항목 · 경로 13,662
3. **BaseVolume 문법** — extrude/loop/aggregate/stack + 관계 동사 44개
4. **VLM 배심** — 눈먼 3인, 같은 루브릭, 앵커 보정
5. **develop 다듬기** — 변이 → 쌍비교 → 챔피언 → 코퍼스

하나라도 빠지면 그 라운드는 반쪽이다.

## BOOK은 이 필지로 온다

책은 **비례**를 주고 필지는 **크기**를 준다. 균일 배율(용적률 목표의 세제곱근,
건폐율과 봉투가 상한)로 이 필지 용량에 맞춘 뒤, **massv2와 같은 게이트**를
통과해야 심사대에 오른다: 서는가, 방이 되는가. 2026-09-04 이전에는 셋 다
없었고, 그래서 5~20% 건폐율짜리 추상 도형과 떠 있는 판이 심사를 받았다.

## 손으로 만지면 안 되는 것

- **`--new-era`로 보드를 비우면 BOOK부터 다시 수입한다.** 시대를 열면 book 좌석이
  같이 사라진다. 두 번 빠뜨렸다.
- **스테이지는 심사원 파일을 지운다.** 배심 뒤에 사이클을 처음부터 다시 돌리면
  방금 받은 판정이 사라진다. `--from=N`으로 재개할 것.
- **`runs/board/*.json`은 덮어쓰기 전에 백업한다.** visual-groups.json을 한 번 잃었다.
