## 2026-07-27 - authoritative modular full-flow contract

The maintained production path is:

`site/law/program graph -> law-derived floor-capacity plan -> UnitBox/BaseVolume
1/1..1/16 -> BOOK typed operators -> LLM-authored GeometryProgram/AST ->
homogeneous 4x4 transforms + boolean compilation -> shared floor contract ->
law/FAR/BCR/parking/capacity gates -> bounded paid VLM review/typed repair ->
selected immutable MASS passport -> elevation agent -> optional one-shot GPT
Image material proposal -> frontend evidence`

Non-negotiable boundaries:

- Storey count is derived from legal height, program capacity and floor-height
  constraints. Five storeys is a test fixture, never a global rule.
- BaseVolume identity and every translate/rotate/scale operation compile through
  homogeneous 4x4 matrices. Booleans and topology checks remain explicit
  geometry operations; a matrix does not replace union/difference/intersection.
- `floor_capacity_plan.py` owns law/program-derived target floor allocation.
  `shared_floor_contract.py` owns the exact accepted plates, floor guides,
  measured areas and the bound selectable capacity band. MASS, replay and
  elevation must carry the same contract and hashes.
- `capacity_routing.py` filters measured selectable capacity before paid VLM.
  Requested aspirational capacity remains visible as evidence, but it cannot
  erase a lower measured band that is still a valid legal/selectable result.
- VLM reviews rendered MASS and returns typed scores/repairs. It does not invent
  geometry, law values, floor count or area. GPT Image is elevation/material
  exploration only and must preserve the selected MASS silhouette and floor
  guides.
- `single_execution/replay.py` is an exact replay path, not regeneration. It
  must preserve geometry hash, stage status and shared-floor evidence before
  handing the MASS to elevation.
- The frontend route `/design/language` is evidence UI for the one selected
  causal execution. Archive thumbnails are alternatives/history, not multiple
  masses inside the selected result.
