## 1장 · 완벽한 단일 정답은 없습니다 — 다목적 최적화 (Multi-Objective Optimization)

매스 디자인은 *면적*, *일조*, *이격* 같은 여러 평가 기준이 동시에 충돌하는 문제다. 면적을 키우면 일조가 줄고, 일조를 확보하려면 면적을 포기해야 한다. *시소*처럼 한쪽이 올라가면 한쪽이 내려간다.

이런 문제를 **다목적 최적화 (Multi-Objective Optimization)** 라고 부른다. 단일 점수로 정답을 정의할 수 없고, 여러 trade-off 후보 중에서 사용자가 선택해야 한다. 본 시스템이 *유전 알고리즘 기반*으로 설계된 이유다.

### 슬라이드에 들어갈 요소
- 헤드라인: **완벽한 단일 정답은 없습니다**
- 부제: *다목적 최적화 (Multi-Objective Optimization)*
- 시각: 시소 그림 — 왼쪽 "면적 극대화", 오른쪽 "일조권 확보"
- 본문 한 줄: *"건축 매스 디자인은 양쪽을 100% 만족시키는 단일 해가 존재하지 않는 다목적 trade-off 문제입니다."*

## 2장 · 만들고, 점수 매기고, 좋은 것끼리 섞기 — 유전 알고리즘 (Genetic Algorithm)

컴퓨터는 무작위로 매스 75개를 생성한다(*초기 population*). 각 매스에 면적·일조 점수를 매기고(*fitness evaluation*), 점수 높은 두 매스에서 특징을 절반씩 뽑아 자식 매스를 만든다(*crossover*). 거기에 약간의 무작위 변형을 추가한다(*mutation*).

이렇게 만들어진 다음 세대 75개를 다시 평가하고, 좋은 것끼리 섞고, 또 평가하고… 이 과정을 50세대 반복하면 처음에는 보이지 않던 좋은 매스가 점진적으로 발견된다. 이 *진화 흉내내기*가 **유전 알고리즘 (Genetic Algorithm, GA)** 이다.

### 슬라이드에 들어갈 요소
- 헤드라인: **만들고 → 평가하고 → 섞고 → 변형**
- 부제: *유전 알고리즘 (Genetic Algorithm)*
- 시각: 사이클 다이어그램 4단계 (Init → Evaluate → Crossover → Mutate)
- 강조 박스: **Population 75 × Generations 50 = 약 825개 매스 평가**
- 본문 한 줄: *"무작위 75개에서 출발해 50세대 진화시키면, 점진적으로 우수한 매스 후보가 발견됩니다."*

## 3장 · 5개 스터디 룸과 우등생 전학 — Island 모델 + Ring Migration

한 그룹 75명을 한꺼번에 진화시키면 우연히 한 방향에 강한 매스가 부모로 자주 뽑혀, *모든 자식이 비슷해지는* 문제가 발생한다. 이를 **조기 수렴 (Premature Convergence, Local Optima)** 이라고 부른다.

본 시스템은 75개를 **5개 섬(Island)** 에 15개씩 나누어 *각 섬을 독립적으로 진화*시킨다. 5개의 서로 다른 진화 경로가 동시에 진행되므로 다양성이 보장된다. 다만 섬을 완전히 분리하면 좋은 유전자가 다른 섬에 못 가니까, **10세대마다 각 섬의 best 2명을 옆 섬의 worst 자리로 이주**시킨다 (*Ring Migration*). *우등생 전학*과 같은 원리다.

### 슬라이드에 들어갈 요소
- 헤드라인: **5개 스터디 룸 + 우등생 전학**
- 부제: *Island 모델 + Ring Migration*
- 시각:
  - 좌측 X: 한 그룹만 진화 → 모두 비슷한 형태 (Local Optima)
  - 우측 O: 5개 섬 + 화살표로 best 이주 (Ring 형태)
- 본문 한 줄: *"75개를 5개 섬으로 나누어 독립 진화시키고, 10세대마다 best 2명을 옆 섬으로 이주시킵니다."*

## 4장 · 처음엔 크게 흔들고, 나중엔 작게 — Adaptive Mutation (0.35 → 0.10)

새 매스를 만들 때 부모로부터 받은 특징 위에 *무작위 변형*을 더한다. 이 변형의 크기를 **mutation rate** 라고 부른다. 너무 크면 부모를 안 닮아서 점수가 엉터리, 너무 작으면 새 시도가 없어서 진화가 정체된다.

본 시스템은 **mutation rate를 0.35에서 0.10으로 시간에 따라 자동 감소**시킨다. 초반에는 *가위·망치로 크게 깎듯이* 다양한 영역을 과감하게 시도(*Exploration*), 후반에는 *핀셋·사포로 미세하게 다듬듯이* 좋은 영역을 정밀화(*Exploitation*)한다. **Adaptive Mutation** 의 핵심 아이디어다.

### 슬라이드에 들어갈 요소
- 헤드라인: **처음엔 크게, 나중엔 작게**
- 부제: *Adaptive Mutation (0.35 → 0.10)*
- 시각: 파동 그래프 (왼쪽 큰 진폭 → 오른쪽 작은 진폭) + 도구 비유 (가위·망치 → 핀셋·사포)
- 강조: **초반 Exploration / 후반 Exploitation**
- 본문 한 줄: *"50세대 동안 변형률이 자동으로 0.35→0.10으로 감소합니다. 사람이 개입할 필요 없습니다."*

## 5장 · 컴퓨터는 메뉴판을 차리고, 건축가가 고릅니다 — Pareto Front + 사용자 결정

50세대 후 결과는 *최고의 매스 한 개*가 아니라 **여러 후보 매스의 집합**이다. 어떤 매스도 *모든 평가 기준에서 다른 매스를 능가하지 못한다* — 면적이 좋으면 일조가 작고, 일조가 좋으면 면적이 작다. 이 *비지배 (non-dominated) 매스들의 집합*이 **Pareto Front** 다.

알고리즘은 Pareto front를 *그래프 곡선* 형태로 출력한다. 한쪽 끝은 *수익형 (면적 극대화)*, 반대쪽은 *환경형 (일조 극대화)*, 중간은 *균형형*. **알고리즘은 결정을 내리지 않는다. 곡선만 그려준다.** 어느 점을 최종 선택할지는 사용자(건축가, 시행사)가 사업 목표에 따라 직접 정한다. 컴퓨터는 *메뉴판*을 차리고, 사람이 직접 골라먹는다.

### 슬라이드에 들어갈 요소
- 헤드라인: **컴퓨터는 메뉴판을 차리고, 건축가가 고릅니다**
- 부제: *Pareto Front + 사용자 결정*
- 시각: 매스 3종 진열 — 수익형 (면적 극대) / 균형형 (타협) / 환경형 (일조 극대), 손가락이 한 점 클릭
- 강조: **알고리즘은 결정 X, 선택지만 제공**
- 본문 한 줄: *"비지배 관계의 매스 후보 집합(Pareto Front)을 제시하고, 최종 선택은 사용자가 사업 목표에 따라 직접 내립니다."*
