## Current Contract

- LLM proposes architectural language and authored parameters.
- Grammar agents may also infer formal principles when the LLM loop is disabled,
  times out, or is intentionally avoided for cost. These candidates are
  grammar-agent authored, not unresolved LLM placeholders.
- ARR MassDSL/source geometry compiler materializes the language.
- Attribution/circuit graph references are used only as an explainability and
  harness pattern: `source/evidence -> concept -> strategy -> critic -> agent
  action`. They are not Neo4j-style storage graphs and not true LLM activation
  graphs unless real model internals are available.
- Legal optimizer and parking verifier are hard gates.
- FAR, BCR, height, parking count, and parking mass-stage checks are not LLM judgments.
- Paper claims are also hard-gated by artifacts:
  - EvoMass claim requires `evolution_trace`, not only quota/diversity sorting.
  - Archi-Agents claim requires critic-to-geometry mutation, not only
    `selection_revision_not_geometry_mutation`.
  - DDADesign claim requires a real daylight/diffusion path, not only VLM
    ranking.
  - MASS claim requires prompt/topology search trace, not only fixed agent
    folders.
- Rule priors may exist, but they must be explicit evidence, not hidden "agent" decisions.
- A mass candidate is not considered architecturally diverse just because it has many volumes or roles.
- Agent modularization must be folder-based, not markdown-only. Global workers
  and MAAS domain agents share the `agent.yaml` / `SOUL.md` / `RULES.md` /
  `memory/MEMORY.md` contract, with runtime adapter/card/contract kept next to
  or explicitly linked from that folder.
- Second-stage preference/VLM distillation must also be an agent folder:
  `ARR/backend/design/maas/agents/preference_distiller_agent/`. It is post-legal
  and cannot override law, parking, or source-geometry gates.
- Cloned VLM preference sources:
  - `clone/Personalized-Text-To-Image-Diffusion`
  - `clone/VisionReward`
  Their usable lesson is pairwise preference profiling plus multi-dimensional
  VLM QA/weighted scoring, not VLM-only final selection.
- Second mass distillation memory is folder-based:
  `docs/ai-session-memory/SECOND_MASS_DISTILLATION/`.
