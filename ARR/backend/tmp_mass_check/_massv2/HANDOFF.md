## 남은 일 — 결과에 미치는 순

**선행 검사 수리:** `full-review-20260906/verification-summary.json`의 144실패·89오류를 원인별로 재현하고 수리한다. 33시간 초과는 미검증이며 계산 비용과 호스트 자원 영향을 구분해 끝까지 실행한다. 대표 두 모형/인증 형식 오류 외의 항목을 추측으로 기존 실패 처리하지 않는다. 아래 기능 작업과 직접 연관되는 실패를 함께 해결한다.

1. **공통 서비스 입력과 기존 사이클 연결:** `service-generality-audit.md`를 따라 request/job의 대지·좌표계·법규 근거·용도/프로그램·추상 저작 지시를 하나의 명시적 context로 저장하고 기존 12단계 coordinator로 전달한다. 현재 HTTP variants/AST 실행은 이 흐름이 아니다. 전역 PNU fallback과 별도 복제 capacity를 제거하고 실제 LegalSite에서 파생한다. job별 brief/board/BOOK registry/feedback/산출물을 격리한다. 엔진·법규식을 새로 복제하지 않는다.
2. **전체 BOOK 계약을 실제 저작 입력에 바인딩:** 현재 역할은 소유자 코드를 읽도록 지시하지만 cycle에는 버전·해시가 있는 완전한 계약 첨부가 없다. live owner에서 생성해 첨부하고 지원/거절 범위를 드러낸다. `book-language-availability-20260906.json`은 현재 기본 공개 연산 75개, registry 76개 중 내부 `book_base_volume` 제외를 기록한다. 그래프 노드와 실행 연산을 혼동하지 않는다. 각 alt의 1~3개 선택은 허용하며 연산 개수 채우기를 목표로 삼지 않는다.
3. **건축적 후보군과 비평을 개선하고 다음 전체 회차 실행:** 영어·추상 프롬프트와 실제 입력으로 솔리드 구성·단면·높이·결합의 서로 다른 논지를 저작한다. comp04 챔피언을 다음 회차에서 실제 소비하는지 확인한다. 원형 보존/법규 적합화가 논지를 훼손하면 공통 원인을 수리한다. 상대 점수와 테스트 통과만으로 현상설계급이라고 판정하지 않는다. 실제 건축가 판단과의 보정은 아직 없다.
4. **주차·출입·프로그램을 공통 조건으로 통합:** 현재 site_planning의 공공업무시설/장애인 적용 가정을 job 입력으로 바꾸고 불명은 미확정으로 유지한다. 실제 연속 차로, 진출입·회전·보행 연결을 함께 탐색해야 한다. 현재 3안은 필요량과 연결 검토를 통과하지 못했다. `parking-search-read-only-audit.md`의 연결 가능한 반례는 검색 개선 가능성이지 최종 해결안이 아니다. 실별 프로그램·피난·접근의 적용 조건은 `conditional-egress-access-20260906.md/.json`에서 이어간다.
5. **설명과 실제 선택 변형의 치수 바인딩:** study의 tradeoff가 원저작 방 깊이 숫자를 선택된 `full_ground`/배치 변형에도 복사한다. comp04 PDF는 원저작 검토 과제/재검증 필요로 명시했다. 향후 치수는 actual shape/certificate에서 파생하거나 정량 주장을 제거한다. 고정한 comp04 생산 산출물을 손으로 고치지 않는다.
6. **필요한 IR 범위 확장:** typed 상·하면, 임의 평면/구멍, 실제 점유·접촉·4×4·렌더는 구현됐다. 일반 3D interval CSG, 곡면 표본 오차의 보장, 관측 지형 접합은 미완료다. 실제 저작이 요구하는 범위를 증거와 함께 확장하고 엔진 변경 시 baseline→굽기→픽셀 비교→변경 형상 재심사를 지킨다.
