# LLM harness

Use a bounded, short, structured author context containing:

- canonical `program_id=neighborhood_living` and WEST access relation;
- normalized coordinate-free legal band relationships;
- whole-building capacity budget and measured deficits;
- allowed base-form capabilities and exact BOOK path offers;
- full Matrix4 contract and operator/type schema;
- measured production-selector outcomes for the prior frozen source across its
  complete bounded BOOK offer, so the LLM does not guess feasibility from path
  names alone;
- concise typed failure feedback, without raw parcel coordinates.

Each response persists its direct response ID, prompt SHA-256, exact ordered
offer IDs/hash, selected-offer membership, AST morphology hash, and source
fragment hash. The LLM must not receive or reproduce parcel coordinates or
law-derived floor breakpoints.
