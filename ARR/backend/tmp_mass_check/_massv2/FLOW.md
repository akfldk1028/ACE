## 한 명령

```

bash skills/mass-cycle/scripts/cycle.sh <라운드명> [문장수]
```

앞 단계의 로컬 생성물은 남을 수 있으므로 HTML 존재만으로 전체 완료라고 판단하지 않는다.
기존 판의 보존은 baseline/era 아카이브가 맡으며, 외부 게시·push는 이 사이클의 작업이 아니다.

2026-09-06부터 단계 영수증으로 복구한다. exit 75는 `runs/cycle-<라운드>/pending.json`에
기록된 저작 또는 배심 입력 대기이며 완료가 아니다. 같은 명령을 다시 부르면 완료 단계와
고정된 심사 그림을 보존한다. `--from=N`도 앞 단계 영수증이 있어야 한다. 입력을 고칠 때는
해당 트랙 생성 성공 전까지만 `--repair-inputs`를 쓸 수 있다. 이미 생성/심사한 형상의 입력을
갈아끼우는 용도로 사용하지 않는다. 정확한 계약은 MassAgent `skills/mass-cycle/SKILL.md`.

## 반드시 같이 도는 다섯

1. **LLM 저작** — 문장을 쓴다
2. **BOOK 탐색** — `generate_maas_creative_100`, 카탈로그·경로는 `book_exploration_graph.py`에서 읽는다
3. **BaseVolume 문법** — 시드·조작과 typed shape. 실행기의 `_VERBS` 및 BOOK 계약이 어휘 소유자다
4. **VLM 배심** — 눈먼 3인, 같은 루브릭, 앵커 보정
5. **develop 다듬기** — 변이 → 쌍비교 → 챔피언 → 코퍼스

하나라도 빠지면 그 라운드는 반쪽이다.

2026-09-06 구성 보존 보완: `select.choose`는 저작 구성 분류가 전달된 경우 기존 셀 선발 뒤
아직 대표되지 않은 적격 구성의 대표안을 추가한다. 같은 셀이라는 이유로 적층·교차·브리지·중정을
배심 전에 지우지 않는다. 실제 기하 중복과 프로그램·물리 게이트는 유지하며, 추가 심사 공급은
우승 보장이 아니다. 적층의 높이별 점유 수는 `family.py`가 실제 실행 결과에서 읽고,
연결 조립의 배치 변환 예산은 `geometry_language/assembly_budget.py`를 공통으로 사용한다.
렌더러는 별개 고체를 임의의 연속 loft로 바꾸지 않는다. 비교 PDF의 전체 탐색 페이지는
완료 회차의 고정 보드·그림 정체성 영수증에서만 읽는다.

사용자의 서비스 요구 정본은 `agents/MassAgent/docs/user-requirements.md`다. 여러 대지에
공통으로 적용하며, 영어 프롬프트는 추상적 건축 원리를 정의하고 대지·법규·프로그램은
입력 데이터로 받는다. 각 alt에 필요한 1~3개 원리/조작만 선택해도 된다. 전체 BOOK 언어를
선택할 수 있고 위 전체 흐름을 활용해야 한다는 요구이며, 한 alt에 모든 어휘를 넣으라는
뜻이 아니다. 어휘 개수나 상대 심사 점수만으로 현상설계급 건축 매스의 증명을 대신하지 않는다.

배심 타일은 최종 매스와 같은 source의 익명 지상·상층 평면 및 표시 절단선 단면을 함께
담는다. 문장·BOOK·앵커·develop 쌍 모두 `presentation.append_jury_drawings`를 사용한다.
BOOK은 export 메시, 일반 저작은 실제 solid 질의를 사용하며, 이름·형상 ID가 있는 sidecar는
private 배심 입력에 넣지 않는다. 그려지지 않은 방·문·계단은 있는 것으로 추정하지 않는다.

문장 develop도 호스트 LLM이 저작한다. `parti-developer` 체크포인트에 정확한 부모
variant·shape ID와 요청 수만큼의 완전한 자식 문장을 제출한다. 중정·진입·실 깊이·단면의
읽히는 약점을 고치고 지배적인 공간 구성은 유지한다. 높이만 바꿨다가 같은 건물로 배달된
변이는 비교안으로 세지 않는다. 입력·실제 쌍이미지를 함께 고정한 뒤 새 배심 3인이 판정한다.

BOOK develop은 step 5 탐색과 다른 저작 계약이다. cycle이 실제 부모의 이름·형상·프로그램
해시·인증을 확인하여 `book-development-parent-contract.json`을 기록한다. 저자는 그 계약에
묶인 `mode: exact-authored-development`, `inherit_parent_dimensions: true`와 완전한
`geometry_programs`를 낸다. 부모의 실제 층수·자체 층고·목표 면적을 상속하고 실제 전달값은
다시 측정한다. 개발 입력 뒤에 임의 BOOK 연산을 붙이거나 입력 순서로 층수를 정하지 않는다.
기존 컴파일·물리화·수입·법규/형상 게이트는 그대로 적용한다. 서로 다른 쌍이 없는 시도는
입력·출력을 보존하고 다음 재개 때 새 `-r2`, `-r3` 저작을 요청한다. step 5의 카탈로그 탐색은
계속 필수이며 이 개발 계약으로 대체하지 않는다.

## BOOK 저작은 서브에이전트가 한다

`--author-mode llm`은 OpenAI를 직접 부르고 그 계정은 크레딧이 없다. 정본은
**`--author-mode payload`**이고, **저자는 현재 호스트 LLM 또는 명시한 저작 에이전트**다.
저자가 읽어야 할 계약은 `geometry_language/llm_adapter.py`의
GEOMETRY_AUTHOR_PROMPT_CONTRACT · BASE_SEED_SPECS · BASE_FORM_SPECS ·
AUTHOR_GEOMETRY_GATE_POLICY와 `creative_program_author.authored_programs_from_payload`
(페이로드 형식과 검증), 그리고 아핀 권위 규칙(유닛 박스 기저 사슬 위 matrix4 하나).

`recipe_fixture`는 회귀·데모용 결정론 소스다. 그걸로 돌리면 십자·L·중정 같은
일반형만 나온다.

## 전후는 시대로 가른다

큰 수정 뒤에는 baseline을 보존하고 **같은 cycle 명령에**
`--new-era "<BEFORE/AFTER 설명>" --baseline <보존 폴더>`를 붙인다.
보존 폴더에는 기존 `runs/board`와 파일별 해시 `manifest.json`이 있어야 한다.
이전 판은 `runs/board-archive-<타임스탬프>`에 통째로 남고, 새 보드에는 시대
이후에 채점된 라운드만 앉는다. 비교는 그 둘을 나란히 놓고 한다.
새 시대도 BOOK payload를 재수입·재심사한다. cycle의 픽셀 비교 결과는 라벨별 전후 정체성을
함께 기록하므로 좌석 주인이 달라진 것을 같은 형상의 품질 향상으로 해석하지 않는다.

## BOOK은 이 필지로 온다

`book_import._to_parcel_size`는 요청 크기를 제안하고, 실제 배치는 source bridge의 XY 행렬과
별도 Z 높이로 정한다. 균일 축척을 실행했다고 가정하지 않는다. `delivered_floor_evidence`가
실제 전달 메시를 원 설계의 변환된 층 중심에서 커널로 절단해 연면적을 합산한다. 원본·전달 메시·
층별 증거가 불일치하거나 층 중심이 불연속 수평면에 걸리면 인증을 거부한다. 평면 목표 미달과
밴드 대리 형상의 면적은 별도로 공개하고 모든 단면 부품을 보존한다. 원 층수는 유지하며,
형상을 줄여 과다한 명시 층수를 숨길 수 없다.
건폐율·용적률·해당 필지 층수 제한과 **massv2의 서는가·방이 되는가 게이트**를
통과해야 심사대에 오른다. 2026-09-04 이전에는 필지 맞춤과 공통 게이트가
없었고, 그래서 5~20% 건폐율짜리 추상 도형과 떠 있는 판이 심사를 받았다.

## 납품 매스는 한 함수를 지난다

`execute.delivered(form, axis, storey_m)` = `realign`(문장이 이름 붙인 선) → `regulated`(아무도
이름 붙이지 않은 근접 정렬을 스냅; 임계값은 `regulate.py`). 런·시퀀스 시트·보드
재건이 전부 이 함수를 지나므로 좌석은 심사받은 그대로 그려진다. 스냅은 **받치는 것을
잃으면 취소**된다(캐리어 겹침 가드, 캐리어 위에 앉은 부분은 층선 스냅 제외) — 첫
배선에서 크로스 바가 판에서 0.4 m 떠 40%가 공중에 있었다.

작은 클립 손실에 대한 자기 도형 보존은 `compile._own_figure`가 판단한다.
보존 범위와 실제 조정은 코드에서 읽고, 결과는 동일 형상의 수치와 그림으로 확인한다.

## 점수는 그림의 것이다

- 심사받은 타일마다 **그림 정체성**(`vlm_shortlist.shape_id`: 렌더러가 읽는 기하 전부의 해시,
  라벨·캡션 제외)이 key.json → shortlist → ledger → board-key로 실린다.
- 수치 인증도 `certificate_id`로 묶는다. 층고만 바뀌어 연면적이 달라져도 옛 점수를 재사용하지
  않는다. 납품 최종 타일·시퀀스 마지막 프레임·평면·단면은 동일한 선택 변형을 다시 그린다.
- 각 배심원은 자기 폴더의 익명 PROMPT와 이미지만 읽는다. 저자 설명·키·기존 점수·다른
  배심원의 판정은 전달하지 않는다. 내부 실행은 `GITAGENT_IO_ROOT`로 read/write 범위를 제한한다.
- **앵커는 정체성이 일치할 때만 탄다.** 엔진이 바뀌어 그림이 달라진 좌석은 앵커가 아니다.
  09-05에 최상위 좌석이 스냅으로 다시 그려진 채 옛 점수 4.9로 앵커를 탔고, 델타 스프레드
  1.32로 자가 안 움직여 한 라운드가 raw로 기록됐다 — 안 바뀐 그림이 0.4~1.0 떨어졌다.
- **자기 라운드 좌석은 자기 앵커가 될 수 없다.** 같은 스테이지에 경쟁 타일과 앵커로 두 번 탔었다.
- **엔진(실행기·컴파일·렌더)이 바뀌면**: 굽기 후 픽셀 diff로 바뀐 좌석을 찾고, 바뀐 라운드는
  재스테이지 → 재심사 → 재채점. 안 바뀐 좌석의 점수만 유효하다.

## 손으로 만지면 안 되는 것

- **`--new-era`를 연 사이클에서도 BOOK을 다시 생성·수입·심사한다.** 기존 좌석은
  함께 아카이브되므로 보존한 payload를 사이클에 공급한다. 수동 BOOK 실행은 하지 않는다.
- **스테이지를 직접 다시 부르지 않는다.** 현재 사이클은 같은 명령으로 재개하면 완료
  영수증과 고정 심사 자료를 보존한다. `--from=N`은 해당 영수증이 있을 때만 쓸 수 있다.
- 엔진/납품 결함을 **두 트랙 모두 채점하기 전**에 발견하면, 실행을 멈춘 상태에서 같은
  cycle에 `--restage-unscored "이유"`를 추가한다. 기존 자료·판정·상태를 해시와 함께 복사
  보존한 뒤 BOOK 수입과 익명 스테이지부터 다시 돌며 새 private 폴더의 새 배심원 3인을
  요구한다. 생성 성공 영수증은 유지한다. 바뀐 동결 파일의 해시 검사를 우회하지 않으며,
  채점이 시작된 라운드는 이 옵션으로 고치지 않고 새 시대/라운드로 간다.
- **`runs/board/*.json`은 덮어쓰기 전에 백업한다.** visual-groups.json을 한 번 잃었다.
